# T01–T28 개별 실행 기록 — 84회

- `T01-R1`: T01 케이스의 첫 번째 재구축 회차. 케이스 구성은 [전체 보고서의 케이스 표](matrix-results-20260911.md#2-케이스-구성)에 있다.
- calibration Recall은 파라미터 선택에 사용한 무필터 90개 질의의 값, evaluation Recall은 별도 평가 질의의 값이다.
- p95는 무필터 검색 900건의 응답시간 95백분위(ms), QPS와 RAM은 필터를 포함한 혼합 실행의 값이다.
- 목표 판정의 `안`·`아래`·`위`는 evaluation Recall이 목표 ±0.01과 어떤 관계인지 나타낸다. 제품 선정 판정이 아니다.
- Recall은 6자리, p95는 3자리, QPS와 MiB는 1자리로 표시한다. 원본 CSV의 Recall·지연시간은 6자리, QPS·CPU는 3자리이며 나머지 원본 필드도 [CSV 사본](assets/matrix-20260911/vector-db-result.csv)에 보존했다.
