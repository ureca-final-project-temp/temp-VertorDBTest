# 실행 결과 문서

현재 기준은 2026-09-11에 완료한 T01~T28 전체 실행입니다. 14개 DB·엔진·인덱스 조합에 두 Recall 목표를 적용하고 세 번씩 재구축해 84개 케이스 결과를 기록했습니다.

## 현재 전체 실행

| 문서 | 확인할 내용 |
|---|---|
| [T01~T28 전체 실행 보고서](matrix-results-20260911.md) | 이번 비교 조건, 전체 결과, 목표 충족과 실제 Recall, 지연·처리량·자원 및 변동 해석 |
| [84회 개별 실행 기록](matrix-runs-20260911.md) | 회차별 측정값과 선택 파라미터를 대조하는 기록 |
| [비교 결과 해석 기준](decision.md) | 개별 목표 판정과 평균 집계의 차이, legacy 필드의 해석 범위 |

이번 보고서는 기존 `eligible`·`passes_*`를 제품 선정·탈락에 사용하지 않습니다. 실제 Recall과 목표 충족 횟수, 성능·자원, 회차 간 변동을 함께 비교합니다. 실제 100k/1M·non-synthetic 데이터·별도 필터 선택도 검증은 이번 84회에 포함되지 않았습니다.

실행 조건은 [현재 실험 프로토콜](../03-benchmark-design/current-protocol.md), 저장 필드와 집계 계산식은 [결과 형식](../06-implementation/result-format.md)을 확인합니다.
