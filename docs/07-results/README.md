# 실행 결과 문서

현재 주 결과는 **새 검색 파라미터 sweep 방식으로 완료한 372개 실측**입니다. 14개 DB·엔진·인덱스 구성을 각각 3회 재구축했고, 회차마다 124개 검색 파라미터를 모두 측정했습니다. Recall 0.90과 0.95는 산포도의 수평 참고선입니다.

모든 Recall 측정값을 보존했습니다. 실제 100k/1M·non-synthetic 데이터·별도 필터 선택도 검증은 이번 372개 측정에 포함되지 않았습니다.

실행 조건은 [현재 실험 프로토콜](../03-benchmark-design/current-protocol.md), 저장 필드와 집계 계산식은 [결과 형식](../06-implementation/result-format.md)을 확인합니다.
